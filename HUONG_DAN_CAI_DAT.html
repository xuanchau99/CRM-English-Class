🚀 Hướng dẫn Cài đặt & Triển khai

Tài liệu hướng dẫn từng bước để chạy dự án EnglishTools trên máy tính cá nhân (Local), kết nối Database và đẩy lên môi trường thật (Vercel).

0

Khởi tạo Cơ sở dữ liệu (Supabase)

Dự án sử dụng Supabase làm Database chính. Trước khi chạy code, bạn phải khởi tạo một dự án Supabase mới.

0.1

Đăng ký tài khoản

Truy cập Supabase.com và đăng nhập bằng tài khoản Github của bạn.

0.2

Tạo Dự án mới (New Project)

Bấm "New Project". Nhập tên dự án (VD: EnglishTools), tạo Database Password (nhớ lưu lại mật khẩu này). Vùng (Region) nên chọn Singapore cho tốc độ nhanh nhất tại VN.

0.3

Thiết lập Schema (Cấu trúc DB)

Sau khi dự án tạo xong (mất khoảng 2 phút). Ở Menu bên trái, chọn "SQL Editor" → "New Query".

Trong thư mục code mà bạn tải về, hãy tìm thư mục supabase/migrations/. Lần lượt mở nội dung các file SQL (ví dụ: 0001_initial_schema.sql, 0002...), copy toàn bộ nội dung dán vào SQL Editor và nhấn RUN để tạo bảng dữ liệu.

1

Hướng dẫn chạy Code ở Local (Máy cá nhân)

Yêu cầu hệ thống:

  • Đã cài đặt Node.js (Phiên bản v18 trở lên). Tải tại: nodejs.org
  • Công cụ quản lý code: VS Code.

Các bước thực hiện:

1.1

Cấu hình biến môi trường

Đổi tên file .env.example thành .env ở thư mục gốc của dự án. Sau đó mở file .env lên và điền 2 đoạn mã lấy từ dự án Supabase của bạn vào:

VITE_SUPABASE_URL=https://[ID_CUA_BAN].supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=eyJhbGci...[KEY_CUA_BAN]...

* Cách lấy: Đăng nhập Supabase → Chọn Project → Settings → API.

1.2

Cài đặt thư viện

Mở Terminal trong thư mục dự án và chạy lệnh:

npm install
1.3

Chạy ứng dụng

Khởi động máy chủ ảo (Dev Server):

npm run dev

Truy cập vào link xuất hiện trên Terminal (Thường là http://localhost:5173).

2

Kết nối Database Supabase bằng DBeaver

Bạn có thể quản trị cơ sở dữ liệu PostgreSQL của Supabase trực tiếp trên máy tính bằng phần mềm DBeaver.

2.1

Lấy thông tin kết nối từ Supabase

Truy cập Supabase Dashboard → Project Settings (Bánh răng) → Database.
Kéo xuống phần Connection parameters, bạn sẽ thấy thông tin:

  • Host: `aws-0-ap-southeast-1.pooler.supabase.com` (ví dụ)
  • Port: `6543` (hoặc `5432`)
  • Database: `postgres`
  • User: `postgres.xxxxx`
  • Password: (Mật khẩu bạn đặt lúc tạo Project).
2.2

Thiết lập trên DBeaver

1. Mở DBeaver → Chọn biểu tượng "New Database Connection" (Cái phích cắm góc trái trên cùng).
2. Chọn cơ sở dữ liệu PostgreSQL → Next.
3. Điền các thông số Host, Port, Database, Username và Password vừa lấy ở trên.
4. Chuyển sang tab "SSL" và chọn SSL Mode là "require" (Bắt buộc với Supabase).
5. Nhấn Test Connection. Nếu thành công, nhấn Finish.

3

Hướng dẫn Đẩy code lên Vercel (Deploy)

3.1

Đẩy Code lên Github

Mở Terminal trong thư mục code và chạy các lệnh Git cơ bản:

git init
git add .
git commit -m "First release Phase 12"
git branch -M main
git remote add origin [LINK_GITHUB_REPO_CUA_BAN]
git push -u origin main
3.2

Triển khai (Deploy) trên Vercel

1. Đăng nhập Vercel.com bằng tài khoản Github.
2. Nhấn "Add New..." → "Project".
3. Tìm Repository `EnglishTools` vừa đẩy lên Github và nhấn "Import".
4. Vercel sẽ tự động nhận diện dự án là Vite. Đừng bấm Deploy vội!

3.3

Điền Biến môi trường (Environment Variables)

Trong màn hình cấu hình Import, mở rộng phần Environment Variables.
Nhập chính xác 2 biến (Key - Value) y hệt như file .env ở bước 1.1:
VITE_SUPABASE_URL
VITE_SUPABASE_PUBLISHABLE_KEY

3.4

Hoàn tất

Bấm nút Deploy màu đen. Vercel sẽ tiến hành Build ứng dụng dựa trên cấu hình (bao gồm cả file vercel.json đã chuẩn bị sẵn để sửa lỗi SPA). Quá trình mất khoảng 1-2 phút.
Xong! Bạn sẽ nhận được đường link Web công khai để chia sẻ cho học sinh và giáo viên.
